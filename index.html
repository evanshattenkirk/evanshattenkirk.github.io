01.2 / Credit workflow

Commercial appraisal review

Consistent review criteria, source-backed red flags, and a human decision at the end.

Days → ~40 min20-min AI-assisted review + 20-min human sign-off
Explore the case+

The problem

Commercial appraisal review took multiple days: manual read-throughs, inconsistent criteria between reviewers, and support hunted down report by report.

What I built

A full-stack review app using LLMs and custom AI agents that standardizes review criteria, surfaces red flags, and pulls supporting evidence from additional sources automatically.

Impact

Turnaround cut to ~40 minutes: a 20-minute AI-assisted review plus a 20-minute human sign-off. Now the team's standard workflow across ~25 commercial appraisals.

01

Central data layer + MCP server

Architected a centralized PostgreSQL database with vector embeddings and a custom MCP server, giving LLM agents and the suite of production tools shared access to loan, property, appraisal, pipeline, and due-diligence data.

02

Automated servicer ingestion

Multi-thousand-row servicer reports land in Google Drive, where a daily scheduled agent detects updates through an MCP connector, parses them, and writes them to the database with no manual entry.
