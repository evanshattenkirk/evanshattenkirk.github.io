Production AI, built from the underwriter's seat

Every tool below is in daily production use. I scoped each one with the teams who use it, architected and built it, and own the roadmap. Code is proprietary, so the demos show the workflows, run on synthetic data.

Commercial Appraisal Review

Full-stack application · LLMs + custom AI agents · Team's standard workflow

Days → ~40 minturnaround, ~25 commercial appraisals to date

The problem

Commercial appraisal review took multiple days: manual read-throughs, inconsistent criteria between reviewers, and support hunted down report by report.

What I built

A full-stack review app using LLMs and custom AI agents that standardizes review criteria, surfaces red flags, and pulls supporting evidence from additional sources automatically.

Impact

Turnaround cut to ~40 minutes: a 20-minute AI-assisted review plus a 20-minute human sign-off. Now the team's standard workflow across ~25 commercial appraisals.

Demo available on request.

Residential Appraisal Review Pipeline

Integrated data extraction · Replaced third-party SaaS

<1 min / reportprocessing, down from 15–20 min manual extraction

The problem

The group paid a third-party SaaS $3,000+/month plus $8 per appraisal and still hand-extracted data for 15–20 minutes per report on top of it.

What I built

An in-house review pipeline with integrated data extraction, replacing both the vendor and the manual step with a single automated flow.

Impact

Cost reduced to <$100/month and $0.02 per appraisal, with processing under 1 minute per report, a ~97% cost reduction at higher throughput.

Executive Exposure & Delinquency Dashboard

Interactive reporting · Source of truth for monthly C-Suite meetings

6 sources → 1 view4 servicer reports + CRM export + investor report

The problem

Exposure and delinquency questions meant stitching together four servicer reports, a CRM export, and an investor report by hand. Slow, stale, and argued over in the room.

What I built

A dashboard that ingests all six sources into one interactive view, portfolio-wide or sliced by servicer, with drill-down to the loans behind any number.

Impact

Adopted as the source of truth for monthly C-Suite meetings. Questions that took days of prep now get answered live, in seconds.
